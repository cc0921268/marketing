## 二、推断假设（基于事实，非确定结论）

**推断 1：音质是当前最普遍的体验短板。**
- 依据：37 条评论提及，占有效评论 37/260（14.2%），排名第 1。
- 边界：这是**提及频次**，不等于严重程度；少数用户强烈抱怨的维度可能排名靠后。

**推断 2：售后服务是第二高频问题，且与第 1 名差距有限。**
- 依据：二者相差 12 条（37 vs 25）。
- 边界：差距在个位数时应视为**同一梯队**，不宜强行排序。

**推断 3：华为 在「音质」维度上的抱怨最集中。**
- 依据：10 条提及 / 该品牌 64 条评论（15.6%）。
- 边界：样本量小的品牌（<20 条）单条提及就会显著抬升比例，需谨慎解读。

**推断 4：OPPO 的负面情绪占比最高（65.7%）。**
- 依据：35 条评论中负面 23/35（65.7%），平均评分 4.1。
- 边界：**合成数据，不代表真实口碑**；且负面率与产品定位、价格带相关，不能单独作为质量判断。

## 五、方法说明与限制

| 项 | 说明 |
| --- | --- |
| 编码方式 | 确定性规则引擎（v0.4），对齐实验2 Skill 的字段与拒答口径 |
| 痛点维度 | 9 类：降噪 / 续航 / 佩戴舒适 / 连接稳定性 / 通话质量 / 音质 / 做工质感 / 售后服务 / 价格性价比 |
| 分母 | 有效评论 260 条（已剔除噪音与品牌型号不一致） |
| 计数 | 多选题口径，一条评论可计多个维度 |
| 证据 | 逐字子串，未改写，可按 review_id 回查 |
| 局限 | 规则引擎的语义理解弱于大模型，否定句、反讽、隐含抱怨可能漏判 |
| 数据 | **合成数据**，结论不可外推为真实市场判断 |
